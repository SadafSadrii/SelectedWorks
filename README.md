# SelectedWorks

Selected art projects by Sadaf Sadri from the past few years.

Open `index.html` to browse the local preview. An HTTP preview or GitHub Pages enables opening projects over the live backdrop and using the browser Back button. The site uses plain HTML, CSS, and JavaScript.

## Updating on GitHub

Open the project's folder and edit its `index.html`. The artwork text and media are inside the `<article>`. Upload images to `assets/media/`, then reference them from the project with `../assets/media/your-image.jpg`. Include image descriptions and credits where appropriate.

## Publishing

In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**. Check the preview at `https://sadafsadrii.github.io/SelectedWorks/` before adding the custom domain.

## Media to verify before moving sdfsdr.com

- Vimeo supplies the homepage backdrop. YouTube supplies the performance video in *It Happened On A Sunday*. Test both players from the GitHub Pages URL and again at the custom domain.
- The four *De/Angular* clips and the *A Prayer Unfolds Itself Into* audio are included locally. The durations in the Cargo captions are retained as artwork metadata and can differ from the length of the posted clips.
- The artwork images, including the animated excerpt in *Cow, Disturbed*, are included locally.
